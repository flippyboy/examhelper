# Official exam-objective sources

Search with the exam code plus `exam` / `objectives` / `skills measured`, then open
the vendor URL. Prefer these hosts:

| Vendor | Where objectives live |
|---|---|
| Microsoft | `learn.microsoft.com/credentials` and `…/certifications/exams/<code>` (“Skills measured”) |
| AWS | `aws.amazon.com/certification/` exam page → exam guide PDF |
| CompTIA | `comptia.org` exam page → “Exam Objectives” PDF |
| Cisco | `cisco.com/c/en/us/training-events/training-certifications/exams/` exam topics |
| Google Cloud | `cloud.google.com/learn/certification` exam guide |
| Red Hat | `redhat.com/en/services/training-and-certification` exam objectives |
| Linux Foundation / CNCF | `training.linuxfoundation.org` or `cncf.io/certification` exam details |
| HashiCorp | `hashicorp.com/certification` exam review guide |
| Broadcom / VMware | Broadcom education catalog; exam guide / blueprint PDF for the current code |
| Palo Alto, Fortinet, ISC2, ISACA | Vendor certification catalog → official exam blueprint / outline |

If the live page disagrees with an older PDF, use the live page and set `version` to
the dated blueprint (e.g. `2024-08`).
